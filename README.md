# UrbanDrive

Sistema de gestão de mobilidade urbana (aluguel de veículos, patinetes e frotas) em C#, aplicação de console. Trabalho prático de POO — PUC Minas.

## Integrantes

- Gabriel Henrique Duarte Ferraz
- João Pedro dos Santos Martins
- Victor Bryan Ferreira Lopes

## Requisitos

- .NET SDK 8.0

## Executar

```bash
dotnet build
dotnet run --project src/UrbanDrive.App     # demonstração da Sprint 1
dotnet test                                 # testes xUnit
```

## Estrutura

- `src/UrbanDrive.Models` — entidades (`Veiculo`)
- `src/UrbanDrive.App` — aplicação de console
- `tests/UrbanDrive.Tests` — testes automatizados
- `docs/` — backlog, planejamento das sprints, diagramas e evidências
